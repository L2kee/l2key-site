# Reel music beds

Background music for the Instagram and TikTok Reels (social/reel.js mixes one under the narration, rotating per post).
All tracks are by HoliznaCC0 and dedicated to the public domain under CC0 1.0, so they can live in this public repo.
Each file is a 70 second cut (starting 15 seconds in), loudness normalized, with a fade in and out.
